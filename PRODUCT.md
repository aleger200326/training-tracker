# Атлетика

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
React, TypeScript, Vite; выбран в утверждённом плане.

## Users
Один пользователь планирует домашние и зальные тренировки, изучает технику и отмечает посещения.

## Product Purpose
Помочь выбрать подходящую тренировку, составить расписание и видеть фактическое выполнение.

## Capabilities and Constraints
Русский интерфейс, большой каталог, локальные личные данные без аккаунта, бесплатные источники упражнений и медиа, публикация через GitHub Pages.

## Evidence on Hand
Каталог free-exercise-db. Некоторые исходные названия и инструкции доступны только на английском.
