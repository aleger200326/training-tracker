GEORGRAD/Вернуться к тренировкам

Конфиденциальность

GEORGRAD хранит данные тренировок отдельно для каждого аккаунта. Эта страница описывает работу текущей версии приложения.

Какие данные сохраняются

Neon Auth обрабатывает адрес электронной почты, пароль и сессию для входа. В базе Neon сохраняются идентификатор аккаунта и данные, которые вы вводите в приложении: профиль, планы, упражнения, расписание и отметки тренировок. Приложение не получает пароль базы данных.

Где находятся данные

Сайт размещён на Vercel, а данные аккаунта и тренировок хранятся в Neon. В браузере остаются настройки языка и темы. Изображения части упражнений загружаются из открытого каталога free-exercise-db. При экспорте JSON копия данных сохраняется в выбранном вами месте на устройстве.

Доступ и управление

Доступ к записи тренировок ограничен политикой базы данных: вошедший пользователь может читать и менять только запись своего аккаунта. Вы можете выгрузить данные в JSON и удалить отдельные записи в приложении. Для вопросов об удалении аккаунта и всех связанных данных используйте страницу вопросов проекта.
