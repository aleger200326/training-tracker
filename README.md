# Атлетика

Личный трекер тренировок для дома и зала.

## Запуск

```bash
pnpm install
pnpm dev
```

Сборка: `pnpm build`. Данные профиля, планов и журнала сохраняются в IndexedDB этого браузера. Перенос между устройствами — через экспорт/импорт JSON в разделе «Профиль».

Каталог содержит 876 упражнений из [free-exercise-db](https://github.com/yuhonas/free-exercise-db) ([Unlicense](https://github.com/yuhonas/free-exercise-db/blob/main/LICENSE.md)) и дополнительное упражнение со степпером. Изображения загружаются с GitHub при наличии сети; два кадра в подробном окне сменяются для демонстрации движения. Не все исходные названия и инструкции переведены на русский. Изображения могут отсутствовать у отдельных упражнений.

Это справочный планировщик, а не медицинские рекомендации.
