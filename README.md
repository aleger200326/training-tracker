# GEORGRAD

Личный трекер тренировок для дома и зала.

## Запуск

```bash
pnpm install
pnpm dev
```

Сборка: `pnpm build`. Данные профиля, планов и журнала сохраняются в IndexedDB этого браузера. Перенос между устройствами — через экспорт/импорт JSON в разделе «Профиль».

Каталог содержит 876 упражнений из [free-exercise-db](https://github.com/yuhonas/free-exercise-db) ([Unlicense](https://github.com/yuhonas/free-exercise-db/blob/main/LICENSE.md)) и дополнительное упражнение со степпером. Изображения загружаются с GitHub при наличии сети; два кадра в подробном окне сменяются для демонстрации движения. Изображения могут отсутствовать у отдельных упражнений.

В шапке можно выбрать русский, узбекский или английский язык и переключить светлую или тёмную тему. Выбор сохраняется в этом браузере. Названия и инструкции встроенного каталога доступны на всех трёх языках; русский и узбекский тексты подготовлены машинным переводом, поэтому перед выполнением упражнения стоит сверять технику с демонстрацией и исходным английским описанием. Пользовательские упражнения и названия созданных планов остаются в языке, на котором их ввели. Переключение языка не отправляет данные профиля или журнала в сервис перевода.

В профиле кнопка «Составить расписание по моим данным» создаёт планы и занятия на ближайшую свободную неделю с учётом цели, уровня, места, оборудования и числа тренировочных дней. Расписание можно затем изменить в разделе «Мои тренировки» и отметить занятия в календаре.

Это справочный планировщик, а не медицинские рекомендации.
