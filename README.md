# GEORGRAD

Трекер тренировок для дома и зала. Интерфейс доступен на русском, узбекском и английском языках, со светлой и тёмной темой. Каталог включает упражнения [free-exercise-db](https://github.com/yuhonas/free-exercise-db) ([Unlicense](https://github.com/yuhonas/free-exercise-db/blob/main/LICENSE.md)).

## Что нужно сделать для запуска облачной версии

1. **Сохраните старые тренировки.** Откройте [старый сайт на GitHub Pages](https://aleger200326.github.io/training-tracker/), перейдите в «Профиль» и нажмите «Экспорт JSON». Сохраните файл. Браузер не разрешает новому адресу Vercel напрямую прочитать данные старого адреса.
2. **Создайте аккаунт Neon.** На [neon.com](https://neon.com/) зарегистрируйтесь через GitHub или электронную почту. Создайте проект с любым именем, например `georgrad`.
3. **Включите вход и доступ к данным.** В проекте Neon включите **Neon Auth** и **Data API**. Скопируйте два HTTPS адреса: **Auth URL** и **Data API URL**. Это публичные адреса сервиса. Строку подключения PostgreSQL с паролем в настройки сайта не вставляйте.
4. **Создайте таблицу.** В Neon откройте **SQL Editor**, вставьте весь файл [`neon/schema.sql`](neon/schema.sql) и нажмите **Run**. Затем обновите схему Data API, если Neon предлагает кнопку **Refresh schema cache**. Политика RLS из файла разрешает пользователю читать и менять только свою запись.
5. **Создайте аккаунт Vercel.** На [vercel.com](https://vercel.com/) войдите через тот же GitHub. Нажмите **Add New → Project**, выберите репозиторий `training-tracker`. Framework Preset: **Vite**. Build Command: `pnpm build`. Output Directory: `dist`.
6. **Добавьте адреса Neon в Vercel.** Перед **Deploy** в **Environment Variables** создайте `VITE_NEON_AUTH_URL` и `VITE_NEON_DATA_API_URL`; вставьте соответствующие HTTPS адреса из шага 3. Добавьте их для Production и Preview. Если деплой уже был сделан, после добавления переменных нажмите **Redeploy**.
7. **Разрешите адрес сайта для входа.** После деплоя скопируйте адрес вида `https://...vercel.app`. В настройках Neon Auth добавьте его в доверенные домены/разрешённые адреса приложения. При добавлении собственного домена укажите там и его.
8. **Перенесите тренировки.** Откройте новый сайт, зарегистрируйтесь, при необходимости подтвердите почту, войдите. В «Профиле» нажмите «Импорт JSON» и выберите файл из шага 1. Перезагрузите страницу, чтобы проверить сохранение. Затем проверьте вход с другого браузера.

Старый сайт GitHub Pages остаётся доступным для экспорта. Данные облачной версии хранятся в Neon, отдельно для каждого аккаунта. JSON файл содержит данные профиля и тренировок: храните его как личную резервную копию.

## Локальная разработка

```bash
pnpm install
Copy-Item .env.example .env.local
```

Заполните `.env.local` двумя HTTPS адресами Neon, затем запустите `pnpm dev`. Производственная проверка: `pnpm build`. `.env.local` исключён из Git.

Регистрация и сессия работают через Neon Auth. Записи загружаются через Neon Data API. Сайт не содержит пароля базы данных. При ошибке загрузки данных редактор блокируется, чтобы случайно не перезаписать сохранённые тренировки.
